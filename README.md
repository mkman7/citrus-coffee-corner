# Citrus Coffee Corner

A small browser-based interactive coffee memory for Citrus.

## How to test locally
Open `index.html` in a browser.

## How to publish
Upload the full folder contents to any static hosting service such as Netlify, Vercel, GitHub Pages, or a standard web hosting file manager.

## Files
- `index.html` — page structure
- `style.css` — visual design
- `game.js` — game logic
- `assets/` — optimized Citrus images

## Spotify
The Spotify playlist is embedded as a player. It does not autoplay; users press play manually.

## Current V1 menu
Coffee: Espresso, Americano, Flat White, Latte, Filter Coffee
Temperature: Hot / Iced where suitable
Milk: Whole Milk, Oat Milk, Almond Milk, Lactose-free Milk
Syrups: No Syrup, Mocha, Hazelnut, Vanilla, Caramel
Sides: Chocolate Walnut Cookie, Tiramisu Cookie, Sour Cherry Chocolate Cookie, Brownie, Smoked Turkey Sandwich, No Side
